# Статус проекта: Telegram-бот Елены Семёновой

Отчёт на 16.08.2026 — что сделано, как всё работает, что нужно для интеграции с сайтом.

## Где всё лежит

- **Код:** публичный репозиторий на GitHub — https://github.com/peremenka73/elena-bot (публичный из-за особенностей хостинга, подробности внизу; секретов там нет)
- **Хостинг:** Bothost.ru, тариф «Базовый» (99₽/мес), бот развёрнут в Нидерландах (Amsterdam) — Telegram заблокирован в России, для ботов доступна только зарубежная локация
- **Бот в Telegram:** @elena_semenova_psyholog_bot
- **База данных и гайды:** хранятся в постоянной папке `/app/data` на сервере (Volume у Bothost) — переживают пересборку и перезапуск бота

## Как бот работает целиком

1. Пользователь пишет `/start`
2. Бот проверяет подписку на канал @elena_semenova_psycholog
   - Не подписан → кнопки «Подписаться на канал» и «Я подписался, проверить»
   - Подписан → сразу меню
3. После подтверждения подписки — меню из 5 гайдов (PDF), кнопка записи на консультацию и кнопка ИИ-ассистента, плюс постоянное меню внизу экрана с теми же тремя разделами
4. Внизу есть меню команд Telegram (значок «/») — `/start`, `/guides`

## Гайды

5 PDF-файлов, выдаются по кнопке, каждый — с подписью-описанием. Лежат в `data/guides/` на сервере (не в git — публичный репозиторий, гайды не должны быть скачиваемы без подписки).

## ИИ-ассистент (DeepSeek)

- 3 бесплатных вопроса на пользователя, счётчик хранится в базе (не сбрасывается при перезапуске)
- Системный промпт: тёплый психолог-консультант по психосоматике/СРК/панике, без диагнозов
- Пока ИИ думает — сообщение «Секунду, думаю над ответом...» + индикатор «печатает»
- После лимита — предложение перейти на сайт (платный чат) и/или записаться на консультацию

## Запись на консультацию (главная новая функция)

Полноценный сценарий бронирования кнопками (без внешнего календаря — в Telegram его нет):

1. Пользователь выбирает формат: 🎥 Онлайн или 💬 Переписка в чате
2. Выбирает дату (ближайшие 14 дней) и время (10:00–19:00, по часу) — всё кнопками
3. Заявка уходит Елене с кнопками «Подтвердить ✅» / «Предложить другое время 🔄»
4. Если Елена подтверждает — пользователь сразу получает подтверждение
5. Если предлагает другое время — Елена тем же способом (дата → время) выбирает 3 варианта, они уходят пользователю кнопками, он выбирает подходящий
6. После подтверждения (в любом сценарии) пользователь получает: дату/время, реквизиты для оплаты (карта и телефон — можно скопировать тапом) и напоминание оплатить за сутки до консультации + приглашение задавать вопросы в чате. Елена получает финальное подтверждение с датой/временем

**Не сделано:** платёжный шлюз (кнопка реальной оплаты картой) — сейчас только реквизиты для перевода. Автоматическое напоминание "за 24 часа" тоже не сделано — пользователь получает этот текст сразу при подтверждении записи, а не отдельным сообщением позже.

## Вопросы и обратная связь

Любой свободный текст от пользователя (не команда, не кнопка) — пересылается **Елене** (не админу). Она отвечает либо Reply на сообщение, либо просто следующим сообщением — уходит тому, чей вопрос был последним без ответа.

## Рассылка

`/broadcast` — только для админа (Ивана, ADMIN_ID). Присылает текст всем, кто писал боту.

## Переменные окружения (.env на сервере, в Bothost)

BOT_TOKEN, ADMIN_ID, CHANNEL_USERNAME, CHANNEL_ID, ELENA_ID, DEEPSEEK_API_KEY — все настроены и работают.

## Известные ограничения

- Реквизиты для оплаты — банковский перевод, не автоматический платёжный шлюз
- Нет автонапоминания об оплате за 24 часа отдельным сообщением (см. выше)
- Календарь записи — не настоящий визуальный, а кнопки «дата → время»
- Хостинг Bothost — молодая платформа (бета), сталкивались с багами в интерфейсе подключения приватных репозиториев (поэтому репозиторий сделан публичным, PDF из него убраны)
