# Папка для PDF-гайдов

Положите сюда 4 файла ровно с такими именами (важно — регистр и написание должны совпадать):

- `srk_diary.pdf` — СРК: дневник на 7 дней
- `panic_4steps.pdf` — Паника: 4 шага
- `relationships_5signs.pdf` — Отношения: 5 сигналов
- `empathy_test.pdf` — Эмпатия: тест

Пока файла нет — бот не упадёт, а просто напишет пользователю, что гайд временно недоступен,
и выведет предупреждение в консоль.
