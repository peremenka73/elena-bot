# Бот Елены Семёновой — раздача PDF-гайдов в Telegram

Простыми словами: этот бот приветствует человека, просит подписаться на канал Елены,
и после подписки выдаёт бесплатные PDF-гайды. Всё работает через официальный Telegram Bot API,
без сторонних сервисов вроде Salebot или ManyChat — весь код у вас на компьютере, и вы
можете менять его сами (или с помощью Claude).

## Что нужно сделать перед запуском

### Шаг 1. Создать бота через @BotFather и получить токен

1. Откройте Telegram и найдите бота **@BotFather** (это официальный бот Telegram для создания ботов).
2. Напишите ему команду `/newbot`.
3. Придумайте имя бота (это то, что видят люди, например «Бот Елены Семёновой»).
4. Придумайте username бота — он обязательно должен заканчиваться на `bot`, например `elena_semenova_bot`.
5. BotFather пришлёт вам **токен** — длинную строку вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Это и есть `BOT_TOKEN`. Никому его не показывайте — это как пароль от бота.

### Шаг 2. Узнать свой Telegram user_id

1. Найдите в Telegram бота **@userinfobot**.
2. Напишите ему `/start`.
3. Он пришлёт в ответ ваш `Id` — это число и есть ваш `ADMIN_ID`. Он нужен, чтобы только
   вы могли пользоваться командой рассылки `/broadcast`.

### Шаг 3. Узнать ID канала

1. Добавьте бота **администратором** в канал @elena_semenova_psycholog (это обязательно —
   без этого бот не сможет проверять, подписан ли человек).
2. Чтобы узнать числовой `CHANNEL_ID` (вида `-1001234567890`), проще всего:
   - Перешлите любое сообщение из канала боту **@userinfobot** — он покажет ID канала.
   - Либо временно добавьте в канал бота **@getidsbot** — он тоже покажет ID.
3. `CHANNEL_USERNAME` — это просто юзернейм канала, у вас это `@elena_semenova_psycholog`.

### Шаг 4. Заполнить файл .env

В папке проекта есть файл `.env.example` — это образец. Сделайте его копию с именем `.env`
(без `.example` на конце) и впишите туда свои значения:

```
BOT_TOKEN=здесь_ваш_токен_от_BotFather
ADMIN_ID=здесь_ваш_числовой_id
CHANNEL_USERNAME=@elena_semenova_psycholog
CHANNEL_ID=здесь_числовой_id_канала
```

Как сделать копию файла:
- **Windows:** щёлкните правой кнопкой по `.env.example` → «Копировать», затем «Вставить»,
  переименуйте копию в `.env`.
- **Через терминал:** команда `copy .env.example .env` (Windows) или `cp .env.example .env` (Mac/Linux).

### Шаг 5. Установить Python-библиотеки

Убедитесь, что у вас установлен Python 3.11 или новее (проверить: `python --version`).

В терминале, находясь в папке `elena-bot`, выполните:

```bash
pip install -r requirements.txt
```

Это установит три библиотеки: aiogram (работа с Telegram), aiosqlite (база данных),
python-dotenv (чтение файла .env).

### Шаг 6. Положить PDF-гайды в папку guides/

Переименуйте свои готовые PDF-файлы гайдов и положите их в папку `guides/` ровно с такими именами:

- `srk_diary.pdf`
- `panic_4steps.pdf`
- `relationships_5signs.pdf`
- `empathy_test.pdf`

Подробности — в файле `guides/README.md`.

Также откройте `config.py` и замените плейсхолдеры `# TODO: текст от Ивана` на реальные
короткие тексты-описания к каждому гайду (можно попросить Claude помочь их написать).

### Шаг 7. Запустить бота

В терминале, в папке `elena-bot`, выполните:

```bash
python bot.py
```

Если всё настроено верно, в консоли появится сообщение:
`Бот запущен и слушает сообщения...`

Теперь откройте вашего бота в Telegram и напишите `/start`.

Чтобы остановить бота — нажмите `Ctrl+C` в терминале.

## Как пользоваться

- `/start` — приветствие и проверка подписки на канал.
- `/guides` — показать меню гайдов ещё раз (если пользователь уже подписан).
- `/broadcast` — рассылка сообщения всем, кто писал боту. Работает только для вас
  (проверяется по `ADMIN_ID` из `.env`). После команды бот попросит прислать текст
  следующим сообщением — и разошлёт его всем.

## Как сделать так, чтобы бот работал круглосуточно

Пока вы запускаете `python bot.py` на своём компьютере — бот работает только тогда,
когда компьютер включён и запущена эта команда. Это нормально для теста, но для реальной
работы (чтобы бот отвечал людям и ночью, и когда компьютер выключен) нужен **сервер**,
который работает постоянно — его называют **VPS** (виртуальный частный сервер).

Как это устроено просто: вы арендуете небольшой сервер за небольшую ежемесячную плату,
загружаете туда те же файлы бота, устанавливаете Python и библиотеки так же, как на своём
компьютере, и запускаете `python bot.py` там. Сервер не выключается, поэтому бот работает
круглосуточно.

Бюджетные варианты (удобны для русскоязычных пользователей, оплата российской картой):

- **Timeweb Cloud** — timeweb.cloud, есть простые тарифы от небольшой суммы в месяц.
- **Selectel** — selectel.ru, также есть недорогие облачные серверы.

На первое время достаточно самого простого/минимального тарифа — боту не нужно много
ресурсов. Если понадобится, Claude может помочь пошагово настроить сервер и запуск бота
на нём (например, через утилиту `screen`, `tmux` или `systemd`, чтобы бот продолжал
работать даже после того, как вы закроете подключение к серверу).

## Структура проекта

```
elena-bot/
├── bot.py                  # точка входа — отсюда запускается бот
├── config.py                # чтение .env и список гайдов
├── database.py               # работа с SQLite (таблицы users и guide_requests)
├── subscription.py            # проверка подписки на канал
├── handlers/
│   ├── start.py             # /start, приветствие, проверка подписки
│   ├── guides.py             # меню гайдов, выдача PDF, /guides
│   └── admin.py              # /broadcast — рассылка для админа
├── guides/                   # сюда кладутся PDF-файлы гайдов
├── data.db                    # база данных SQLite (создаётся автоматически)
├── requirements.txt            # список нужных Python-библиотек
├── .env.example                # образец файла с настройками
└── .env                        # ваш файл с настройками (создайте сами, не публикуйте)
```

## Важно

- Файл `.env` содержит секретный токен бота — никогда не публикуйте его и не выкладывайте
  в открытый доступ (например, на GitHub в публичный репозиторий).
- Файл `data.db` — это база данных со списком подписчиков. Периодически делайте её копию
  (просто скопируйте файл `data.db` в надёжное место), чтобы не потерять данные.
